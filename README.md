# Console Store Simulator

## Описание проекта
Консольное приложение, имитирующее работу розничного магазина. Симулятор разделен на две основные роли:
- **Владелец магазина**
- **Покупатель**

Каждая роль имеет уникальный набор действий, механик и случайных событий, что создает глубокую и реалистичную экономическую симуляцию.

## Стандарт именования
Используется стиль **lower_snake_case**.

## Предварительная структура проекта
- **src/main.cpp** - точка входа, запускает главное меню

- **src/menu.cpp** - реализация интерфейса командной строки
- **src/buyer.cpp** - логика работы покупателя
- **src/seller.cpp** - логика работы продавца
- **src/supplier.cpp** - логика работы с поставщиками
- **src/buyer_bot.cpp** - бот для автоматической симуляции покупателя
- **src/storage.cpp** - работа с файловым хранилищем данных и многое другое...
- **src/events.cpp** - система случайных событий
- **src/utils.cpp** - вспомогательные функции
- **src/global.cpp** - инициализация глобальных переменных

- **data/all_products.txt** - файл со списком всех возможных товаров.
- **data/shop_data.txt** - файл со статистикой магазина и списоком его товаров.

- **include/menu.h** - объявление меню
- **include/buyer.h** - объявление покупателя
- **include/seller.h** - объявление продавца
- **include/supplier.h** - объявление поставщика
- **include/buyer_bot.h** - объявление бота-покупателя
- **include/storage.h** - объявление хранилища
- **include/events.h** - объявление системы событий
- **include/utils.h** - вспомогательные утилиты
- **include/global.h** - глобальные переменные
- **include/constants.h** - глобальные константы
- **include/structures.h** - структуры данных
